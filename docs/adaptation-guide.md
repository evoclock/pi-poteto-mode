# Adaptation guide: pstack on Pi

The skills are Lauren Tan's pstack v0.15.25 (MIT). This guide lists where my Pi
adaptation has to differ from upstream because upstream relies on a Cursor tool
or feature that Pi does not provide in the same form. Everything else follows
the upstream text as closely as Pi allows.

The per-skill tables at the end are generated by
`node scripts/adaptation-report.mjs <path-to-upstream-pstack> --markdown`. The
script searches each upstream skill for the Cursor feature and quotes the first
sentence in the matching `-pi` skill that handles it. I rerun it on every
upstream sync and update the summary below by hand.

## Summary by feature

| Feature | Upstream behaviour | Pi handling today | Status and plan |
|---|---|---|---|
| Task / subagents | Fans work out to Cursor `Task` subagents and ships Cursor agents in `agents/`. | Skills use workers only when an approved Pi coordinator/worker dispatch route and the `development` role exist; otherwise they work sequentially. No agent files ship. | Partial. I plan a subagent mapping as a Pi extension in a separate package. |
| TodoWrite / task lists | Tracks phases with Cursor's todo tool. | Uses Pi session tasks when a task tool is loaded; otherwise a local checklist. | Partial. Depends on the task tool loaded in the session. |
| AskQuestion | Asks structured multiple-choice questions with Cursor's question tool. | Asks one plain chat question, multiple-choice in wording, and waits for the owner. | Done. |
| CloudAgent / background agents | Hands work to Cursor cloud or background agents. | Not mapped. Skills do not start background or unattended work. | Planned after the subagent mapping. |
| MCP | Uses Cursor MCP servers when present. | Uses MCP only with an explicit grant; no broad server discovery. | Done. |
| Browser / computer use | Drives the app through Cursor's browser or computer use. | Checks the real entry point with whatever approved tool the project provides; this package ships no browser tool. | Partial. |
| Cursor rules (`.mdc`) | Writes always-applied rules such as `~/.cursor/rules/pstack-models.mdc`. | Writes only the project-local `.pi/pstack-model-roles.v1.json`; shared rules live in `skills/how/WORKFLOW_BOUNDARIES.md`. | Done. |
| Model names and effort | Names models, effort levels, panels and `auto`/inherit fallbacks. | Two exact roles, `development` and `independent-review`, set by `/skill:setup-pstack-pi`; no fallback. | Partial. I plan more roles once I can test them in Pi. |
| Cursor transcripts | Reads Cursor agent transcripts. | Reads only an approved transcript path and range; otherwise reports the gap. | Partial. |
