# Changelog

All notable changes to this package are documented here. This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-11-14

### Added
- Restored the pstack 0.15.36 procedures, 23 full playbooks, source references and explicit Pi boundaries. The package registers 57 instruction skills; the video procedure remains planned.
- Added operator-selected reasoning budgets and ordered panel roles to project-local setup, without operational model defaults.
- Added a fail-closed macOS TLC route, instruction-recall checks and deterministic upstream restoration checks.

### Changed
- Clarified owner-held merge and publication boundaries, worker routing, and unavailable runtime capabilities.
- Moved repository CI checks to Buildkite.

## [0.1.0] - 2026-10-19

### Added
- Initial Pi instruction adaptation of pstack, with package installation instructions, comparison notes and upstream attribution.
